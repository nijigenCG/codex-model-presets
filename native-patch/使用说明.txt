Codex 模型按钮补丁 1.1.0（Apple Silicon / macOS 13+）

1. 双击「Codex 模型按钮补丁.app」。
2. 可修改两个按钮的名称、模型 ID、推理强度和 Standard/Fast。
3. 当前回复结束后，点击「保存配置并安装」。安装器会备份应用、检查副本、退出并重新打开 Codex。
4. 输入栏原模型选择器旁会显示两个按钮。点击即切换当前聊天，成功后恢复输入焦点。

Sol：GPT-6.1 Sol / XHigh / Standard
Luna：GPT-6 Luna / Max / Fast
以上为未配置时的默认值。名称和模型留空也使用该位置的默认值。
「恢复默认配置」会填回默认值；再点击「保存配置并安装」生效。
配置文件：~/Library/Application Support/Codex Model Presets Patch/presets.json
配置在更新 Codex 后仍保留；直接修改 JSON 后需重新安装补丁。

1.1.0 修复 1.0.0 因本地签名保留厂商受限权限而无法启动的问题。
安装前检查这些权限并验证系统进程加载；内部框架和助手保留官方签名。
重启后观察进程 5 秒；打不开或立即退出时会自动恢复原版并再次打开。
仍需实际安装后确认聊天界面，进程存活检查无法识别白屏。

卸载：再次打开安装器，点击「卸载并恢复原版」。
Codex 更新：重新打开安装器安装；若提示界面结构不支持，需更新本补丁。

这是非官方补丁，会修改 app.asar 并进行本地 ad-hoc 签名。原版整包备份位于：
~/Library/Application Support/Codex Model Presets Patch/Backups/
首次打开未公证安装器时，macOS 可能要求在系统设置「隐私与安全性」中允许打开。
重新签名后，macOS 可能再次询问 Codex 的麦克风、辅助功能等权限。
本地签名无法保留厂商限定的应用组、推送和钥匙串组声明，依赖它们的功能尚未验证。
按钮不支持锁定模型的 Agent/Aeon 聊天；账号没有对应模型或 Fast 权限时按钮置灰。
若原版更新器无法更新，请卸载补丁恢复官方签名后更新，再重新安装补丁。

不需要 Python、Node、辅助功能模拟点击或独立聊天界面。
源码：https://github.com/nijigenCG/codex-model-presets
